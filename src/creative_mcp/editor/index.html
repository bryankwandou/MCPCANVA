Cara kerja

Browser yang mengukur, Canva yang menyimpan.

Canva Connect API tidak bisa menaruh teks atau gambar ke dalam desain. MCP Canva memakai Chrome Anda sendiri yang sudah login Canva, dikendalikan lewat DevTools Protocol, jadi hasilnya tersimpan langsung di akun Anda.

Render & ukur

HTML dibuka di Chrome headless pada ukuran desain. Setiap node teks dan <img> diukur: posisi, font, ukuran, tebal, warna.

Pisahkan latar

Semua yang bukan teks atau gambar (bentuk, gradasi, SVG, grup bertanda data-canva="raster") dirender sekali menjadi satu gambar latar beresolusi 2×.

Rakit di Canva

Desain baru dibuat di Canva, latar dan gambar diunggah, lalu tiap teks ditambahkan sebagai kotak teks asli. Setiap langkah diverifikasi; kalau ragu, dibatalkan.

Tools MCP

Yang bisa dipanggil agen Anda.

canva_html_to_canva

Ubah file HTML menjadi desain Canva native dalam satu panggilan. Mengembalikan link desain, elemen yang masuk, dan error per elemen.

canva_native_build

Rakit atau tambahkan elemen ke desain dari spec JSON: image (path, x, y, w) dan text (teks, font, ukuran, warna, x, y, w).

canva_browser_upload

Unggah gambar atau video ke Uploads Canva lewat Chrome yang sudah login.

canva_browser_status

Cek Chrome (port 9222) sudah jalan dan akun Canva sudah login.

Yang ikut jadi native

  • Teks: posisi, font, ukuran, tebal, warna, rata kiri
  • Gambar & logo sebagai elemen gambar terpisah
  • Judul desain dan ukuran kanvas kustom

Yang masih jadi gambar latar

  • Bentuk, gradasi, dan dekorasi SVG
  • Grup yang diputar (tandai data-canva="raster")
  • Efek teks seperti text-shadow
Pasang

Tiga perintah, lalu minta agen Anda membuatnya.

$ git clone https://github.com/bryankwandou/mcpcapcutandcanva && cd MCPCANVA $ pip install -e . $ claude mcp add canva -s user -- mcp-canva # langsung dari terminal, jalur kode yang sama dengan tool MCP: $ mcp-canva html spanduk.html "Spanduk LCB 2026"
